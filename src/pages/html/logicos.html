Operadores Lógicos

Definição

Os operadores lógicos em JavaScript são usados para combinar ou inverter valores booleanos (true ou false). Eles são essenciais para tomar decisões dentro de um programa, sendo amplamente utilizados em condições de teste, loops e validações.

Como funcionam?

Os operadores lógicos avaliam expressões que retornam valores booleanos. Eles permitem verificar múltiplas condições simultaneamente ou inverter o resultado de uma condição.

Principais Operadores Lógicos

Operador Nome Descrição Exemplo Resultado
&& E (AND) Retorna true se todas as condições forem verdadeiras true && false false
|| OU (OR) Retorna true se pelo menos uma condição for verdadeira true || false true
! NÃO (NOT) Inverte o valor booleano !true false
