Introdução ao JavaScript

O que é JavaScript?

JavaScript é uma linguagem de programação usada principalmente para criar páginas web interativas e dinâmicas.

Função principal:

  • Permite adicionar comportamentos a sites, como animações, validação de formulários, menus dinâmicos, atualizações de conteúdo sem recarregar a página (via AJAX) e muito mais.

Onde é executado?

  • Originalmente, o JavaScript roda no navegador do usuário, mas hoje também pode ser executado no servidor, usando tecnologias como Node.js.

Características:

  • Linguagem interpretada (não precisa ser compilada)
  • Baseada em objetos e eventos
  • Suporta paradigmas de programação como o funcional e o orientado a objetos
  • É essencial no desenvolvimento web, junto com HTML (estrutura) e CSS (estilo)

Usos comuns:

  • Interatividade em páginas web
  • Criação de aplicações web completas (Front-end e Back-end)
  • Desenvolvimento de aplicativos móveis e desktop (React Native, Electron)
