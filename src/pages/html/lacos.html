Laços de Repetição

Definição

Os laços de repetição ou loops em JavaScript são estruturas que permitem executar um bloco de código várias vezes, com base em uma condição ou contagem. Eles são fundamentais para automatizar tarefas repetitivas e reduzir a duplicação de código.

Como funcionam?

Um loop avalia uma condição antes (ou depois) de cada iteração e executa o código enquanto a condição for verdadeira. Alguns loops usam contador, outros percorrem coleções de elementos como arrays ou strings.

Principais Laços de Repetição

Laço Descrição Sintaxe Exemplo
for Executa um bloco um número determinado de vezes for(inicialização; condição; incremento) for(let i=0; i<5; i++){ console.log(i); }
while Executa enquanto a condição for verdadeira while(condição) let i=0; while(i<5){ console.log(i); i++; }
do...while Executa pelo menos uma vez, depois verifica a condição do{ bloco } while(condição) let i=0; do{ console.log(i); i++; } while(i<5);< /td>
for...of Percorre elementos de arrays ou strings for(let item of array) for(let x of [1,2,3]){ console.log(x); }
for...in Percorre propriedades de objetos for(let chave in objeto) let obj={a:1,b:2}; for(let k in obj){ console.log(k); }
