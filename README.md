# 🪄 Magical JS ✨  
> *Um grimório digital de feitiços em JavaScript — onde lógica e magia se encontram.*

<img align="right" width="150" src="https://i.pinimg.com/originals/23/0d/6f/230d6fe581cf3f5131979c7a9c9ded35.gif">

Bem-vindo(a) ao **Magical JS**, um portfólio encantado criado para reunir meus **exercícios de JavaScript**, com direito a **HTML**, **CSS** e uma pitada de **magia pastel-creepy**.  
Aqui, cada página é um pequeno feitiço de código e cada lista é um capítulo do meu grimório digital 🧙‍♀️💻  

---

## 🌸 Tema & Inspiração  
O **Magical JS** mistura duas estéticas que eu amo:  
- o **mundo kawaii** dos animes — com cores suaves, brilhos e fofura  
- o **lado creepy e misterioso** — com tons sombrios, roxos e símbolos místicos  

O resultado?  
💖 *Uma experiência mágica, fofa e levemente sombria — como uma bruxinha pastel que programa à luz da lua.* 🌙  

---

## 🏰 Estrutura do Projeto  

```
magical-js/
│
├── index.html               → página inicial com introdução
├── /listas/                 → páginas das listas de exercícios
│     ├── lista1.html
│     ├── lista2.html
│     └── ...
│
├── /css/                    → estilos encantados (tema kawaii creepy)
│     ├── style.css
│     ├── navbar.css
│     └── listas.css
│
└── /js/                     → feitiços em JavaScript ✨
      ├── main.js
      ├── lista1.js
      └── ...
```

Cada **lista** contém:
- 🧾 uma introdução temática sobre o conteúdo da lista  
- 💫 cards interativos com demonstrações dos exercícios  
- 🪞 áreas de input e botões “Invocar” para testar os feitiços JS

## 🌙 Como visualizar o projeto

Você pode ver o **Magical JS** diretamente pelo GitHub Pages:  
👉 [**Acessar o Grimório**](https://seuusuario.github.io/magical-js)  

Ou clonar e rodar localmente:
```bash
git clone https://github.com/seuusuario/magical-js.git
cd magical-js
```
Depois, basta abrir o arquivo `index.html` no seu navegador 🪄
