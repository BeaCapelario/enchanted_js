Este repositório apresenta o desenvolvimento de um portfólio pessoal construído com JavaScript puro. O foco principal deste projeto foi demonstrar habilidades técnicas através de uma interface interativa, utilizando manipulação de elementos dinâmicos e organização de código front-end.

---

### O que foi explorado:
* Interatividade Dinâmica: Criação de componentes que reagem às ações do usuário sem recarregar a página.
* Manipulação de DOM: Alteração de conteúdos, classes e estilos em tempo real.
* Estrutura de Projetos: Organização de scripts, estilos e ativos de forma escalável.
* Design Responsivo: Adaptação do layout para diferentes dispositivos e tamanhos de tela.
* Efeitos Visuais: Implementação de animações e transições controladas via JavaScript.
